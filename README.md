# Product Warranty Claim Processing Platform

## Project Overview
The Product Warranty Claim Processing Platform is a web application designed to manage customers, products, warranties, and warranty claims in one place.

## Problem Statement
Manual warranty claim processing can be time-consuming and difficult to track. This project aims to make the process more organized through a digital platform.

## Features
- View and manage customers
- Add and view products
- Manage warranty information
- Submit and view warranty claims
- Update customer information
- Delete customer records
- Display dashboard counts

## Technologies Used
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Java, Spring Boot, Maven  
**Database:** MySQL-compatible database  
**Version Control:** Git and GitHub  
**Deployment:** Vercel for frontend and Railway for backend

## Application Workflow
1. Customer information is registered.
2. Products are added to the platform.
3. Warranty details are managed.
4. Warranty claims are submitted and reviewed.
5. Users can view the available records.

## Running the Project Locally

### Backend
Navigate to the backend folder and run:

```powershell
.\mvnw.cmd spring-boot:run
```

### Frontend
Open `frontend/index.html` using a local development server.
